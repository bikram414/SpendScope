# 🚀 Project Problem Statement
Build a responsive personal finance dashboard that helps an individual understand where money is going. It should feel
intentional and visually polished, not like a generic admin template.
# TARGET USER
The Target Users will be modern professionals,creatives and tech workers who view personal finance as a lifestyle design and self care,rather than rigid acounting.
People who are interested in finace and also wants to know where their spending are going with brief analytical data records and statistical analysis.
